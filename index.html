ML systems · Research in progress

Adaptive Systems

Can smaller feature representations make inference faster while preserving prediction quality?

I built a CPU pilot that crosses full-width and PCA-reduced features with FP32 and INT8 storage. It measures end-to-end latency and feature memory, and selects a static configuration on validation data before held-out evaluation.
